# HTML & CSS Learning and Practice

A hands-on repository containing practical examples and exercises for learning **HTML5 and CSS3**, covering webpage structure, forms, layouts, styling, animations, and responsive design concepts.

This repository documents my practice and learning journey in frontend web development through small, focused examples.

## 🎯 Objective

The goal of this repository is to build a strong foundation in HTML and CSS and understand how webpages are structured, styled, and organized.

The examples focus on:

* HTML webpage structure
* CSS styling
* Page layouts
* Forms and input elements
* Flexbox and Grid
* Text formatting
* Tables and lists
* Headers and footers
* Animations
* Basic interactive webpage elements

## 🚀 How to Run

No special installation is required.

### Option 1: Open Directly

1. Clone the repository.
2. Open any `.html` file in a web browser.
3. Experiment with the HTML and CSS code.
4. Modify the code and observe the changes.

### Option 2: Using VS Code

Clone the repository:

```bash
git clone https://github.com/sashirekha2527/HTML-CSS.git
```

Open the project in VS Code and launch the HTML files using a browser or the Live Server extension.
